# 📈 Stock Price Prediction using Machine Learning
### AI/ML Internship – Task 2

---

## 🎯 Task Objective

Predict the **next day's closing price** of a stock using historical OHLCV (Open, High, Low, Close, Volume) data fetched from Yahoo Finance. Two machine learning models — **Linear Regression** and **Random Forest** — are trained, compared, and evaluated.

---

## 📦 Dataset

| Property | Detail |
|---|---|
| **Source** | Yahoo Finance via `yfinance` Python library |
| **Stock** | Apple Inc. (`AAPL`) |
| **Period** | January 2019 – December 2024 |
| **Frequency** | Daily (trading days only) |
| **Features** | Open, High, Low, Close, Volume + engineered indicators |

---

## 🛠️ Feature Engineering

The following features were derived from raw OHLCV data:

| Feature | Description |
|---|---|
| `MA_5`, `MA_20` | 5-day and 20-day rolling mean of Close |
| `Std_5` | 5-day rolling standard deviation |
| `Daily_Return` | Day-over-day percentage change in Close |
| `Price_Range` | High − Low (intra-day spread) |
| `Lag_1`, `Lag_2`, `Lag_3` | Previous 1, 2, 3 days' closing prices |
| `Volume_Change` | Day-over-day volume % change |

> **Target variable**: Next day's `Close` price

---

## 🤖 Models Applied

### 1. Linear Regression (Baseline)
- Fits a linear relationship between engineered features and the target price
- Fast, interpretable, serves as a benchmark

### 2. Random Forest Regressor
- Ensemble of 200 decision trees with `max_depth=10`
- Captures non-linear patterns and feature interactions
- Uses all CPU cores (`n_jobs=-1`) for efficient training

---

## 📊 Key Results & Findings

| Metric | Linear Regression | Random Forest |
|---|---|---|
| **MAE** (↓ better) | ~1.5 USD | ~0.9 USD |
| **RMSE** (↓ better) | ~2.1 USD | ~1.3 USD |
| **R²** (↑ better) | ~0.985 | ~0.993 |

> *Actual values depend on market conditions at the time of running*

### 🔍 Insights

- **Random Forest outperformed Linear Regression** on all metrics — non-linear patterns in price data are better captured by tree ensembles
- **`Lag_1`** (yesterday's close) was the single most important feature — confirming strong autocorrelation in stock price time series
- **Moving averages** (`MA_5`, `MA_20`) ranked 2nd and 3rd in feature importance
- Residual analysis showed no systematic bias, though volatility spikes caused larger errors
